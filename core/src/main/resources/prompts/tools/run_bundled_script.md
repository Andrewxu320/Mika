Run a script that ships with an App/website knowledge entry or a skill and is marked runnable in its manifest. knowledge_read and skill_read list such scripts with scriptSource: pass that as source and the script's path as script. The file extension picks the interpreter (.py python3, .mjs/.js node, .sh sh). Each item of args reaches the script unchanged; there is no shell in between.

secretEnv hands stored keys to this one run as environment variables, written NAME=entry where entry is a name from secret_save (e.g. AMAP_KEY=amap). The values are not part of the arguments, the result or the run record, so use this instead of writing a key into a file or a command. Scripts that need the network are marked in the manifest; if the user has not allowed scripts to go online, the call is refused and you should tell them where to turn it on.
