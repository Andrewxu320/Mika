Store a key or token the user gave you, encrypted on this phone. Use it when a later step needs a credential that should not be repeated in the conversation: bundled scripts read it through run_bundled_script's secretEnv, so you never need to see it again. name is a short lowercase id, e.g. amap. days is how long to keep it (1-365, default 30); it is deleted automatically when it expires. Never write the value into a file, a message or a task description, and never read a file that holds it. The result gives the name, the expiry and the last four characters only.
