# 重新评估策略

只能从已验证或已渲染的修订版本开始。询问采用 `whole-trip`、`selected-day` 还是 `upcoming-legs` 作用域。保留已完成且无关的路段、先前证据、能力快照和上一份不可变快照。

刷新能力和相关证据，然后只重新评估选定路段。比较差异前，写入一份带时间戳的新快照。将每项发现分类为 `new`、`escalated`、`reduced`、`resolved`、`expired`、`unchanged` 或 `newly-unknown`。证据过期且没有替代证据时，当前结论应变为新出现的未知状态，绝不能暗中标记为已解决。

变更报告开头应列出针对新增阻断项、风险升级和未知关键覆盖的操作。新的阻断性发现可以生成 B 计划提案，但在用户明确接受前，必须保持已确认的规范路线和接受标志不变。

可复用的手动提示词：“使用当前可用能力，按[整个行程 / 日期 ID / 后续路段 ID]范围重新检查此行程。保留先前快照，报告证据时效性和全部七种变更类别；提出路线变更但不应用，然后验证并重新渲染当前修订版本。”
