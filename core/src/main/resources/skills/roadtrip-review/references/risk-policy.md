# 道路与天气风险策略

针对计划时间和行驶方向评估每个驾驶路段。每项发现都应分别保存 `severity`、`confidence`、`coverage`、`status`、`unknowns`、证据 ID、受影响路段、时间窗口和建议操作。

## 执行关卡

| 条件 | 路段关卡 |
| --- | --- |
| 存在与路线匹配且仍生效的权威封路通告或无法通行状况 | `not-executable` |
| 必须更改路线以避开阻断性风险 | `modification-required` |
| 在限时复查或采取缓解措施的条件下可以通行 | `executable-with-monitoring` |
| 关键通行性或天气证据不可用 | `insufficient-evidence` |
| 已检查所有必需维度，且不存在未解决的阻断项、关注项或关键覆盖缺口 | `passed` |

行程汇总遵循单调性：按以下顺序采用各路段中限制最强的关卡：`not-executable`、`modification-required`、`insufficient-evidence`、`executable-with-monitoring`，最后是 `passed`。任何有利维度都不能通过平均抵消阻断项，关键覆盖缺口会阻止结果成为 `passed`。

## 评估维度

- 道路通行性：封闭状态、限制、施工、路面与车辆不匹配、季节性通行条件，以及与路线的相关性。
- 天气暴露：预警重叠、降水、冰雪、风、能见度、温度和地形放大效应。
- 驾驶强度基线：标记时长过长、距离过远、到达过晚或休息不足，但不得编造确切出发时间。
- 海拔基线：将海拔快速上升、过夜海拔过高和缺少高原适应信息与道路状态分开标记。
- 补给与救援基线：识别偏远长路段，以及燃油或充电、通信和掉头方案的不确定性。
- 备选方案质量：对于可以合理改道的阻断项，检查是否存在完整且经过验证的 B 计划。

过期证据仍作为历史记录保留。通行结束后才生效的预警不应限制该路段；需说明两者时间不重叠。对于单一来源报告的严重道路冲毁，可以保留其潜在阻断严重程度，同时将置信度和覆盖保持为低，并将核实作为应对措施。
